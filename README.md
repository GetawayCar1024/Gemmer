## 获胜条件 / $\texttt{Condition}$

若游戏结束时幸存者存活，则幸存者获胜；否则，若淘金客存活，则淘金客与卧底获胜；否则，守卫获胜。

结束游戏有三种方式：

- 尝试从空牌堆中摸牌。
- 从淘金客的回合结束开始，直到淘金客的下一个回合结束，淘金客全程持有同一张真宝石。
- 淘金客死亡。

## 手牌 / $\texttt{Card}$

手牌分为功能牌、酒牌、宝石牌与装备牌四个类型。

- 打出手牌应满足一些基础的条件，如“至少拥有一张手牌”等，下文中不再赘述。
- 若打出手牌时满足使用条件，但最终不满足，则这张牌失效。
- 打出的牌将会明牌进入弃牌堆。
- 所有手牌与牌堆顶部牌的牌背与都是明视的。

### 功能牌 / $\texttt{F-Card}$

#### 摆放 / $\texttt{F-Place}$

- 使用效果：选择自己的任意一张手牌，将其放置到牌堆的指定位置（位置不公开）。

#### 赠礼 / $\texttt{F-Give}$

- 使用效果：选择自己的任意一张手牌，并选择一个非自己的玩家，将选定的手牌赠予选定的玩家。

#### 豪夺 / $\texttt{F-Rob}$

- 使用效果：选择一个非自己的玩家的一张牌，将这张牌据为己有。

#### 交易 / $\texttt{F-Trade}$

- 使用效果：选择一个非自己的玩家，与他交换一张同类型的手牌（使用者选择类型，双方自行选择手牌）。

#### 吞吐 / $\texttt{F-Shuffle}$

- 使用效果：将自己的所有手牌洗入牌堆，打乱牌堆，并从牌堆顶部摸与原本手牌数量相同数量的手牌。

#### 好吃 / $\texttt{F-Eat}$

- 使用效果：选择一个玩家（允许是自己），让他从牌堆顶部摸两张牌。

#### 挖宝 / $\texttt{F-Hunt}$

- 使用效果：从牌堆指定位置摸一张牌。

#### 要不起 / $\texttt{F-Skip}$

- 使用效果：立即结束当前回合。

#### 已读乱回 / $\texttt{F-Pardon}$

- 使用条件：有前置功能牌。
- 使用效果：否定上一张打出的功能牌。

#### 你不准用 / $\texttt{F-Noway}$

- 使用条件：有前置功能牌。
- 使用效果：与打出上一张功能牌的玩家石头剪刀布，若获胜则上一张功能牌失效，同时获得上一张功能牌；否则无效。

#### 开枪 / $\texttt{F-Shoot}$

- 使用效果：指定一个玩家，让他弃一张牌入牌堆；可以作为 开枪（响应） / $\texttt{F-Shoot\ (Reaction)}$ 使用。

#### 开枪（响应） / $\texttt{F-Shoot\ (Reaction)}$

- 使用条件：自己被开枪。
- 使用效果：设自己被开枪应弃 $x$ 张牌，指定一个玩家，让他弃 $x + 1$ 张牌入牌堆。
- 备注：下文中的 开枪 / $\texttt{F-Shoot}$ 是两种 开枪 的统称。

#### 爱装不装 / $\texttt{F-Equip?}$

见 装备 / $\texttt{Equipments}$ 一节。

### 酒牌 / $\texttt{W-Card}$

- 使用条件：从回合开始持有。

#### 琼浆 / $\texttt{W-Nectar}$

- 使用效果：从牌堆顶部摸三张牌。

#### 苹果酿 / $\texttt{W-Apple}$

- 使用效果：指定一个非自己的玩家从牌堆顶部摸两张牌，自己再从牌堆顶部摸两张牌；也可以自己先摸对象再摸。

#### 白酒 / $\texttt{W-Liquor}$

- 使用效果：从牌堆顶部摸三张牌，再从手牌中选择三张牌，将每张牌发给选定的非自己的玩家。

#### 啤酒 / $\texttt{W-Beer}$

- 使用效果：使用的同时必须打出一张非啤酒的酒牌，视为喝了两杯酒；打出第二张酒牌不被视为使用，但若其有效果也将同时触发。

#### 美酒 / $\texttt{W-Wine}$

- 使用效果：从牌堆顶部摸一张牌。

#### 赝品酒 / $\texttt{W-Fake}$

不可使用。

#### 鸩酒 / $\texttt{W-Toxic}$

不可使用。

若你回合结束时手中持有 鸩酒 / $\texttt{W-Toxic}$，那么你将进入濒死状态。

#### 国王酒 / $\texttt{W-King}$

不可使用。

若 国王酒 / $\texttt{W-King}$ 离手，需要额外弃一张手牌入牌堆；若你回合结束时手中持有 国王酒 / $\texttt{W-King}$，那么你将进入濒死状态。

国王酒在牌堆中是普通酒牌，但在手牌中是明牌，即在手牌中需被明视。

### 宝石牌 / $\texttt{G-Card}$

- 使用条件：从回合开始持有。

#### 黄金 / $\texttt{G-Gold}$

真宝石。

- 使用效果：弃 $3$ 张功能牌入弃牌堆，并查验一个玩家的身份。

#### 翡翠 / $\texttt{G-Emerald}$

真宝石，不可使用。

#### 玛瑙 / $\texttt{G-Agate}$

真宝石，不可使用。

#### 白玉 / $\texttt{G-Jade}$

真宝石，不可使用。

若 白玉 / $\texttt{G-Jade}$ 离手，可以选择是否玉碎，若玉碎则 白玉 / $\texttt{G-Jade}$ 直接进入弃牌堆。

#### 赝品宝石 / $\texttt{G-Fake}$

不可使用。

### 装备牌 / $\texttt{E-Card}$

见 装备 / $\texttt{Equipments}$ 一节。

## 装备 / $\texttt{Equipments}$

- 装备牌有其特定的效果，但当且仅当它被装配时才对装配它的玩家生效。
- 爱装不装 / $\texttt{F-Equip?}$ 是一张与 装备 有关的功能牌，其被打出时同样可以被响应。
- 装配一张装备牌需要保证回合开始时持有它，同时打出一张 爱装不装 / $\texttt{F-Equip?}$，随后将装备牌放在装备槽中，视为装备牌离手，被装配的装备牌不属于手牌。
- 一个玩家同时只能装配一张装备牌；当一张装备牌被装配时，将明视该装备牌。
- 在使用装备牌的效果后，装备牌具有一定的冷却时间，期间装备牌无法生效；冷却被定义为回合结束的次数，即自己的回合结束时减一，为零时装备牌可以生效；部分装备牌在被装配时有初始冷却。
- 打出一张 爱装不装 / $\texttt{F-Equip?}$ 后，可以选择装配装备牌，或者选择一个已装配装备牌的玩家（允许是自己）并将他的装备牌放回他的手牌，随后这张装备牌的冷却清零。

### 披风 / $\texttt{E-Mantle}$

- 冷却：$0$。
- 触发类型：被动。
- 触发效果：豪夺不可被响应；豪夺后可以选择将豪夺的牌分发给指定玩家（允许不分发）。

### 圣甲虫 / $\texttt{E-Scarab}$

- 冷却：$0$。
- 触发类型：被动。
- 触发效果：摆放不可被响应；摆放可以摆放其他玩家的牌。

### 怀表 / $\texttt{E-Watch}$

- 冷却：$1$。
- 触发类型：主动。
- 触发效果：选一张已装配的装备牌，使其冷却加一或减一。

### 权杖 / $\texttt{E-Sceptre}$

- 冷却：$2$。
- 触发类型：主动。
- 触发效果：观看牌堆顶部四张牌，并任意重排放回牌堆顶部。

### 王冠 / $\texttt{E-Crown}$

- 冷却：$3$。
- 触发类型：主动。
- 触发效果：选择一张非装备牌，到下次自己的回合开始前，所有人不能使用这种牌。

### 圣杯 / $\texttt{E-Chalice}$

- 冷却：$3$。
- 触发类型：主动。
- 触发效果：视为喝了一杯 琼浆 / $\texttt{W-Nectar}$。

### 明镜 / $\texttt{E-Mirror}$

- 冷却：$4$。
- 初始冷却：$2$。
- 触发类型：主动。
- 触发效果：查验一个玩家的身份。

### 圣戒 / $\texttt{E-Ring}$

- 冷却：无。
- 触发类型：无。
- 触发效果：无。
- 说明：可以在自己的回合调整宝石的位置，宝石可以被放在 圣戒 / $\texttt{E-Ring}$ 上，圣戒 / $\texttt{E-Ring}$ 上最多有一个宝石；圣戒 / $\texttt{E-Ring}$ 上的宝石不能被操作（包括职业）；如果 圣戒 / $\texttt{E-Ring}$ 离开自己的装备槽，则宝石回到自己的手牌中，视为宝石离手；圣戒 / $\texttt{E-Ring}$ 上的宝石属于自己的手牌；冷却对 圣戒 / $\texttt{E-Ring}$ 没有意义。

## 职业 / $\texttt{Occupation}$

- 下文中，触发 的表现为翻开职业牌。
- 触发次数为整场游戏的触发次数。
- 称职业可用当且仅当有剩余的触发次数。
- 复原职业指不明视职业并将职业的使用次数清零。

### 医者 / $\texttt{O-Doctor}$

- 触发条件：有玩家濒死。
- 触发类型：主动。
- 触发效果：解除他的濒死状态，并让他弃掉手牌中所有的 鸩酒 / $\texttt{W-Toxic}$ 与 国王酒 / $\texttt{W-King}$（视为他喝了酒）。
- 触发次数：$1$。

### 骑士 / $\texttt{O-Knight}$

- 触发条件：喝酒。
- 触发类型：被动。
- 触发效果：查验一个玩家的身份。
- 触发次数：无限。

### 欺诈师 / $\texttt{O-Liar}$

- 触发条件：自己濒死。
- 触发类型：被动。
- 触发效果：忽略一张 鸩酒 / $\texttt{W-Toxic}$ 或 国王酒 / $\texttt{W-King}$ 一回合。
- 触发次数：$3$。
- 说明：该职业永远不会被翻开，包括触发时。

### 魔法师 / $\texttt{O-Sorcerer}$

- 触发条件：无（可在任意时刻触发）。
- 触发类型：主动。
- 触发效果：将所有玩家手牌中（除 圣戒 / $\texttt{E-Ring}$ 上的宝石外）的所有宝石沉底。
- 触发次数：$1$。

### 国王 / $\texttt{O-King}$

- 触发条件：自己回合。
- 触发类型：主动。
- 触发效果：指定一个玩家，将 国王 / $\texttt{O-King}$ 明牌放入他手牌中，视为国王酒，但在牌堆中为明牌。
- 触发次数：$1$。

### 鉴定师 / $\texttt{O-Appraiser}$

- 触发条件：无（可在任意时刻触发）。
- 触发类型：主动。
- 触发效果：指定一个玩家的一张暗牌酒或宝石，将其明视并视为赝品，若本身为赝品则不计次数；被鉴定的酒或宝石回牌堆或摸牌堆时恢复；最多只能鉴定一张宝石。
- 触发次数：$2$。

### 商人 / $\texttt{O-Trader}$

- 触发条件：自己回合。
- 触发类型：主动。
- 触发效果：首次触发时自带一次交易效果；主动发起交易时，可以自己的非酒牌视为任意类型的牌。
- 触发次数：无限。

### 僧人 / $\texttt{O-Monk}$

- 触发条件：自己回合 或 被开枪。
- 触发类型：主动 或 被动。
- 触发效果：手中所有的开枪被视为要不起；不能开枪或被开枪（被开枪时亮职业）；使用要不起时，若当前回合已经 $\texttt{PICK}$，则可以选择将 $\texttt{PICK}$ 的牌放入牌堆顶部并立即结束回合。（参见 回合 / $\texttt{Round}$ 一节。）
- 触发次数：无限。

### 收藏家 / $\texttt{O-Collector}$

- 触发条件：手牌中持有至少两张非 鸩酒 / $\texttt{W-Toxic}$ 与 国王酒 / $\texttt{W-King}$ 的酒牌或至少两张宝石牌。
- 触发类型：主动。
- 触发效果：只要在自己的回合满足条件，就可以选择挖宝一次。
- 触发次数：无限。

### 侦探 / $\texttt{O-Detective}$

- 被动效果：手牌中所有 赝品宝石 / $\texttt{G-Fake}$ 视为 黄金 / $\texttt{G-Gold}$。
- 触发条件：自己回合。
- 触发类型：被动。
- 触发效果：使用 黄金 / $\texttt{G-Gold}$ 时仅用消耗 $2$ 张功能牌。
- 触发次数：无限。

### 贤者 / $\texttt{O-Sage}$

- 被动效果：手牌中所有 赝品酒 / $\texttt{W-Fake}$ 视为 美酒 / $\texttt{W-Wine}$。
- 触发条件：使用 美酒 / $\texttt{W-Wine}$。
- 触发类型：被动。
- 触发效果：美酒 / $\texttt{W-Wine}$ 改为从弃牌堆中随机选择三张牌，再从这三张牌选择一张加入自己的手牌。
- 触发次数：无限。

### 魔术师 / $\texttt{O-Magician}$

- 触发条件：自己回合。
- 触发类型：主动。
- 触发效果：交换两张暗牌身份牌或手牌。若交换的是身份牌且身份牌是职业，那么职业复原。
- 触发次数：$1$。

### 引渡人 / $\texttt{O-Psychopomp}$

- 触发条件：有玩家死亡。
- 触发类型：主动。
- 触发效果：将死亡玩家的职业复原并作为自己的职业，若之前有通过 引渡人 / $\texttt{O-Psychopomp}$ 获取的职业，则用新职业替换原职业。整个过程中，引渡人 / $\texttt{O-Psychopomp}$ 始终有效。
- 触发次数：无限。

### 法官 / $\texttt{O-Judge}$

- 触发条件：自己回合。
- 触发类型：主动。
- 触发效果：指定一个玩家，让他手牌数量弃至小于等于自己的手牌数量。
- 触发次数：$1$。

### 酒鬼 / $\texttt{O-Alcoholic}$

- 触发条件：喝酒。
- 触发类型：被动。
- 触发效果：豪夺一个玩家一张牌。
- 触发次数：无限。

## 游戏机制 / $\texttt{Mechanics}$

### 准备 / $\texttt{Preparations}$

游戏正式开始前：

1. 主持人随机分发身份（暗牌）。
2. 主持人从所有职业中选择 $10$ 张作为本场职业并公开。
3. 主持人随机分发职业（暗牌）。
4. 主持人公开剩下的 $4$ 张职业。
5. 所有玩家将自己的身份拿在手中并闭眼。
6. 幸存者翻身份牌，淘金客睁眼查看。
7. 淘金客闭眼，幸存者从 $4$ 张职业中选一张，将其与自己的身份（幸存者）交换。该职业将作为幸存者的身份（也可以理解为第二职业），依然可以发动职业技能，但发动就代表自爆幸存。
8. 幸存者闭眼。
9. 所有玩家睁眼。
10. 打乱牌堆。
11. 每个玩家从牌堆顶部摸 $4$ 张功能牌，若摸到非功能牌则洗进牌堆。

随后开始游戏。

### 回合 / $\texttt{Round}$

轮到玩家回合时，玩家可以依次打出任意张手牌，并在任意时刻从牌堆顶部摸一张牌。一回合必须摸恰好一张牌，这次摸牌记作 $\texttt{PICK}$，要不起 / $\texttt{F-Skip}$ 不受此限制。

### 响应 / $\texttt{Reaction}$

以下三种牌属于响应牌：

- 已读乱回 / $\texttt{F-Pardon}$（在下文中简称为 P）。
- 你不准用 / $\texttt{F-Noway}$（在下文中简称为 N）。
- 开枪（响应） / $\texttt{F-Shoot\ (Reaction)}$。

开枪 / $\texttt{F-Shoot}$ 在下文中简称为 S，除 P 与 N 外的功能牌在下文中简称为 F。

打出响应牌的过程被称为响应。

以下是 F 被响应的过程：

1. F 与响应牌形成一个栈，出栈的牌默认进入弃牌堆。
2. 若栈空，跳到 5。
3. 定义 有效牌 为栈顶第一张非 P 的牌，等待对有效牌的响应（P 或 N）；特别地，若有效牌是 S 且生效，同时等待对 S 的响应（S）。
4. 若有玩家响应，响应牌入栈，跳到 2。若没有玩家响应：
   - 若有效牌生效：
     - 若有效牌是 F，执行 F 的效果，跳到 5。
     - 若有效牌是 N，反复出栈直到 N 出栈，石头剪刀布；若 N 生效，栈顶牌出栈并入玩家手牌。跳到 2。
   - 若有效牌失效，反复出栈直到有效牌出栈，跳到 2。
5. 栈中所有牌出栈，响应结束。

栈中牌的状态的判定规则如下：

- 从栈顶开始遍历，栈顶牌生效。
- 若当前牌失效，下一张牌生效。
- 若当前牌未知：
  - 若当前牌是 P 或 N，下一张牌未知。
  - 若当前牌是 F 或 S，下一张牌生效。
- 若当前牌生效：
  - 若当前牌是 P，下一张牌失效。
  - 若当前牌是 N，下一张牌未知。
  - 若当前牌是 F 或 S，下一张牌生效。
- 显然，有效牌一定生效或失效。

### 濒死 / $\texttt{Dying}$

玩家进入濒死状态后，认为他手中所有 鸩酒 / $\texttt{W-Toxic}$ 与 国王酒 / $\texttt{W-King}$ 生效，并依次进行以下操作。若中途进入了死亡状态或解除了濒死状态，那么立即退出以下操作。

- 若场上有可用的 医者 / $\texttt{O-Doctor}$，可以选择是否看医生。
  - 若看了医生：
    - 若 医者 / $\texttt{O-Doctor}$ 救了，那么濒死状态解除，并弃掉手牌中所有的 鸩酒 / $\texttt{W-Toxic}$ 与 国王酒 / $\texttt{W-King}$；
    - 若 医者 / $\texttt{O-Doctor}$ 没救，那么立即进入死亡状态。
- 若自己的职业是 欺诈师 / $\texttt{O-Liar}$ 且可用，则触发技能。
- 片刻后进入死亡状态。

**注意**：鉴定师 / $\texttt{O-Appraiser}$ 可以在任何时刻发动技能，包括玩家进入死亡状态之前。

### 死亡 / $\texttt{Death}$

一个玩家死亡后，将展示他的手牌与身份。

随后弃掉他手牌中所有的 鸩酒 / $\texttt{W-Toxic}$ 与 国王酒 / $\texttt{W-King}$，并从下家开始，一个玩家选一张牌，直到把所有牌选完。

### 喝酒 / $\texttt{Drink}$

当一张酒牌对一个玩家生效时，该玩家被认为喝了一次酒。

### 圣遗物 / $\texttt{Relics}$

国王酒与装备牌被统称为 圣遗物 / $\texttt{Relics}$。
